# competicao_rdp
Repositório desenvolvido para a competição da disciplina Reconhecimento de Padrões (Prof. Roney Nogueira, IFCE). O projeto implementa do zero (sem scikit-learn) um classificador supervisionado — com opção entre DMC, Bayes/MAP Gaussiano (LDA/QDA), k-NN ou Parzen (KDE) — aplicando-o aos conjuntos de dados Two Moons, Banana e Ripley.
